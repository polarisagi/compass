# 北极星画像（Polaris Compass）

> 开源、免费、不收集数据的职业与性格自我了解工具。由 [PolarisAGI](https://polarisagi.online) 发起。

## 能做什么

| 模块 | 题数 | 用时 | 来源 |
|---|---|---|---|
| 大五人格 | 50 | 约 6 分钟 | IPIP Big-Five Factor Markers（公有领域） |
| 朋友他评 | 50 | 约 6 分钟（朋友来做） | 同上，他评版本 |
| 职业兴趣（RIASEC） | 60 | 约 8 分钟 | 改编自 O\*NET Interest Profiler Short Form |
| 工作价值排序 | 6 | 约 2 分钟 | 分类参考 O\*NET，文字为原创 |
| 自我访谈 | 14 | 约 15 分钟 | 原创 |
| 情绪状态（可选） | 16 | 约 3 分钟 | PHQ-9 + GAD-7 |
| 导入你自己的题库 | — | — | 用户自行提供，见 [题库格式](docs/题库格式.md) |

**特点：**
- **「你眼中的自己」和「朋友眼中的你」对比。** 朋友在自己的设备上作答，生成一段结果码发给你，你粘贴进来就能看到对比。全程不经过任何服务器。
- **零数据收集。** 纯静态网页，所有作答只保存在浏览器的 localStorage 里，可以导出和恢复备份。
- **只内置允许公开分发的题目。** 其他量表可以由用户自行导入，本项目不提供这些内容。

## 运行

纯静态网页，不需要构建。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

也可以直接部署到 Cloudflare Pages、GitHub Pages 等任何静态托管服务。由于使用了 ES 模块，需要通过 HTTP 访问，不能直接双击打开 `index.html`。

## 目录

```text
index.html          页面入口
css/style.css       样式（浅色和深色模式）
js/instruments.js   内置题库（每个模块都注明了来源和条款）
js/scoring.js       计分（纯函数）
js/custom.js        自行导入题库的校验和计分
js/app.js           页面逻辑
docs/题库格式.md     自行导入题库的 JSON 格式
docs/授权申请.md     向原作者申请收录授权的记录和信件模板
NOTICE.md           第三方内容的来源和条款
声明.md              使用声明（与网页「声明」页一致）
```
