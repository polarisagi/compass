# 自行导入的题库格式

北极星画像允许用户在**自己的浏览器里**导入题库。导入的文件只保存在本机，不会上传，也不会进入本项目。

> **请只导入你有权使用的题目。** 很多学术量表只允许用于非商业研究，有的明确禁止公开分发。你需要自己确认，并遵守原作者的条款。不要把含有受版权保护题目的题库文件公开传播，也不要提交到本仓库（`.gitignore` 已经排除了 `*.private.json` 和 `my-questionnaires/`）。

## 格式

```json
{
  "format": "polaris-compass/questionnaire@1",
  "id": "my-scale",
  "name": "量表名称",
  "source": "作者、年份、出处",
  "intro": "作答说明",
  "min": 1,
  "max": 5,
  "labels": ["非常不同意", "不太同意", "中立", "比较同意", "非常同意"],
  "items": ["第 1 题的文字", "第 2 题的文字", "第 3 题的文字"],
  "scales": {
    "分量表 A": [1, -2],
    "分量表 B": [3]
  }
}
```

| 字段 | 要求 |
|---|---|
| `format` | 固定为 `polaris-compass/questionnaire@1` |
| `id` | 只能用字母、数字、下划线和连字符，最多 40 个字符；同一个 id 再次导入会覆盖原来的 |
| `name` | 必填，最多 60 个字 |
| `min`、`max` | 整数，`max` 大于 `min`，两者相差不超过 10 |
| `labels` | 数量必须等于 `max - min + 1` |
| `items` | 1 到 300 条 |
| `scales` | 每个分量表是一组题号，从 1 开始。**负数表示反向计分**：反向计分后的得分为 `min + max - 作答值` |

**计分方式：** 每个分量表取所有题目（反向题先转换）的平均分。只有该分量表的所有题目都答完，才会显示分数。如果原量表有更复杂的计分方法（例如 PVQ 需要减去全部题目的平均分，以消除个人作答习惯的影响），需要你自己在导出结果后另行计算。

**安全：** 导入时，文字里的 `<` 和 `>` 会被去掉，未知字段会被丢弃。
